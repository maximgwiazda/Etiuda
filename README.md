# Etiuda 1, the legacy version

This branch holds only Etiuda 1: the single file `v1/Etiuda.html` with its sample catalog. It is what
[etiuda.dev/v1](https://etiuda.dev/v1) and
[maximgwiazda.github.io/Etiuda/v1/Etiuda.html](https://maximgwiazda.github.io/Etiuda/v1/Etiuda.html) serve.
1.16.8 is its last release.

Etiuda 1 is free and open source under the MIT License: see `v1/LICENSE`. The Etiuda name and the Etiuda marks
are not covered by that licence. `Etiuda.html` at the top is a redirect to `v1/Etiuda.html`, kept so older links
carry on working.

Etiuda 2 is built on the `main` branch, under its own licence, the Etiuda Source-Available Licence; none of its
code is on this branch.
