Install for all users into Program Files, or into a folder that neither Users, Authenticated Users, Everyone, INTERACTIVE nor Domain Users (S-1-5-32-545, S-1-5-11, S-1-1-0, S-1-5-4, and the domain's own SID ending -513) can write to, and whose parent folder they cannot write to either. A silent install gives no warning when this is not so.

Instalację dla wszystkich użytkowników umieszcza się w Program Files albo w folderze, do którego, ani do jego folderu nadrzędnego, nie mogą zapisywać grupy Users, Authenticated Users, Everyone, INTERACTIVE ani Domain Users (S-1-5-32-545, S-1-5-11, S-1-1-0, S-1-5-4 oraz SID domeny zakończony na -513). Instalacja w trybie cichym nie ostrzega, gdy tak nie jest.
